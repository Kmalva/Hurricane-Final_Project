# Frontend Polish Skill

Make the website feel like a finished data journalism project.

Design requirements:
- Strong hero section.
- Clear visual hierarchy.
- Consistent spacing.
- Consistent typography.
- High contrast text.
- Smooth scrolling.
- Sticky scrollytelling sections.
- Clean buttons and controls.
- No broken layout at laptop sizes.
- No overflowing charts.
- No tiny axis labels.

Use CSS variables for:
- background color
- text color
- accent color
- warning/heat color
- muted text
- card background

Add final polish:
- subtle background gradients
- chart cards
- hover states
- active states for filters
- caption/source text
- final takeaway section
