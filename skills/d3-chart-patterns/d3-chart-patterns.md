# D3 Chart Patterns Skill

Use reusable D3 chart patterns.

Every chart should:
- Set margins correctly.
- Use responsive width.
- Have labeled axes.
- Have readable ticks.
- Include a chart title or nearby heading.
- Include annotations when useful.
- Include tooltips for detailed values.
- Avoid overplotting.
- Use transitions carefully.

Preferred charts:
- Line chart for temperature over time.
- Bubble timeline for hurricane events.
- Small multiples for comparing yearly climate/hurricane variables.
- Scatterplot for exploring relationships between temperature and storm activity.

Do not:
- Use pie charts for time trends.
- Use 3D effects.
- Use misleading dual axes unless absolutely necessary and clearly labeled.
- Overload one chart with too many encodings.
